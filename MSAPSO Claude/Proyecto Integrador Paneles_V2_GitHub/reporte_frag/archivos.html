Cómo reproducir (desde la carpeta V2, con las dependencias de requirements_V2.txt)

python3 validar_simulador_V2.py                      # Paso 1: simulador V2 vs V1
python3 evaluar_baselines_V2.py                      # Pasos 2-3: MSAPSO fiel y variantes
python3 train_V2.py --wait 5e-3 --seed 0 --timesteps 1000000 --n-envs 4 --tag ppo_5ms_full_s0     # entrena un PPO (~8-15 min)
python3 analisis_final_V2.py                         # estadistica consolidada (usa cache en resultados_V2/raw/)
python3 graficas_resultados_V2.py                    # figuras
python3 construir_reporte_V2.py                      # este PDF
