Cómo reproducir (con requirements_V4.txt, Python 3.10 o superior)

python3 probar_entorno_V4.py             # Paso 3: entorno valido
python3 baselines_nivel1_V4.py           # Paso 4: referencias sin aprendizaje
python3 cota_diagnostico_V4.py           # Paso 5: cota supervisada (diagnostico)
python3 grid_reinforce_V4.py             # Paso 6: malla de REINFORCE (unos minutos)
for s in 0 1 2; do python3 ppo_nivel1_V4.py --N 7 --K 5 --steps 1000000 --seed $s; done   # Paso 7 (~85 s c/u)
python3 entrenamiento_largo_V4.py        # Paso 8
python3 graficas_V4.py                   # figuras
python3 construir_reporte_V4.py          # PDF (requiere Google Chrome en macOS y pdftotext)

Todo corre en CPU. Los entrenamientos del nivel 1 tardan segundos o pocos minutos, no horas.
